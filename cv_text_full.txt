2. JogjaCourt — Platform Booking Lapangan Badminton
Tech Stack: React · Tailwind CSS · FastAPI · Supabase
Link: jogja-court.vercel.app | GitHub: yazid-solo/JogjaCourt
• Mengembangkan platform booking lapangan badminton berbasis web untuk wilayah D.I. Yogyakarta, memungkinkan
pemilik/admin gedung memasarkan ketersediaan lapangan secara online dan penyewa melakukan pemesanan tiket
dalam satu platform terpusat tanpa perlu datang langsung ke lokasi. Dibangun dengan arsitektur full-stack: frontend
React (Vite + Tailwind CSS) dengan tema dark mode dan aksen gold, backend FastAPI dengan lebih dari 30 REST API

tiga peran pengguna (customer, admin operasional, super admin). Dilengkapi fitur lanjutan meliputi login sosial Google,
live chat berbasis WebSocket, dan auto-cancel booking terjadwal melalui APScheduler.
