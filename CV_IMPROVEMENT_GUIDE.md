## 🎯 Tips Desain Visual CV

> **Gunakan desain 1–2 halaman saja.** HRD rata-rata membaca CV hanya 6–10 detik
> pertama. Jangan isi terlalu padat.

### Rekomendasi:
- **Font:** Inter / Poppins / DM Sans — bersih dan modern
- **Warna:** Hitam + 1 warna aksen (biru tua `#1e3a5f` atau teal `#14b8a6`)
- **Bullet point:** Mulai dengan **kata kerja aktif**
  (Membangun, Mengelola, Mengintegrasikan, Merancang)
- **Hindari:** Terlalu banyak emoji, foto besar, font dekoratif, latar warna gelap

### Urutan Halaman yang Disarankan:
```
1. Header         (Nama, Kontak, Link GitHub & Portfolio)
2. Ringkasan Diri (3–4 kalimat yang spesifik)
3. Keterampilan   (Tabel dengan level jujur)
4. Proyek         (2–3 proyek terbaik + link)
5. Pengalaman     (Urutan dari terbaru)
6. Pendidikan
7. Organisasi
8. Sertifikat     (5–7 paling relevan)
```
