Hubungi Saya

Halo! Saya Muchamad Yazid Ardani, biasa dipanggil Yazid. Saat ini saya adalah mahasiswa Semester 5 Teknik Informatika di Universitas Nahdlatul Ulama Yogyakarta. Kalau ditarik mundur, perjalanan saya ke dunia IT sebenarnya lumayan melenceng. Waktu SMK, saya mengambil jurusan Teknik Kendaraan Ringan Otomotif. Dulu keseharian saya lebih akrab dengan mesin dan oli bengkel, jauh sebelum akhirnya saya memutuskan banting setir ke dunia pemrograman.

Transisi dari bengkel mesin, kemudian sempat menjajal dunia affiliate marketing, mengajari saya satu hal penting: proses belajar itu tidak selamanya lurus, dan kemampuan adaptasi adalah kuncinya. Mentalitas pantang menyerah ini yang sekarang saya pakai buat debugging kode error, merancang alur logika, dan mengejar ketertinggalan di dunia teknologi yang serba cepat.

Sekarang, fokus saya adalah memperkuat dasar-dasar Software Engineering. Saya sedang asyik mendalami Web Development, menghubungkan API ke Database, dan bereksperimen merancang antarmuka lewat UI/UX Design. Saya sadar kalau kerja di industri pasti butuh kolaborasi, makanya saya biasakan pakai version control (Git/GitHub) dari sekarang, plus pelan-pelan berkenalan dengan Docker untuk paham konsep deployment.

Selain ngoding, saya juga terbiasa dengan urusan administrasi dan data pakai Microsoft Office. Buat saya, efisiensi kerja itu nomor satu. Oleh karena itu, saya sering tandem bareng AI Assistants. Teknologi ini sangat membantu untuk menaikkan produktivitas harian—mulai dari mencari ide, membaca referensi kode, sampai beresin tugas-tugas repetitif agar saya bisa fokus ke logika utamanya.
